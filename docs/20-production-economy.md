# 20. 生产、商店与经济数据

## 20.1 制造配方

`produce_db.txt` 记录：

- 成品；
- 数量；
- 所需技能与等级；
- 材料和数量；
- 锻造、制药、料理等生产类别。

成功率通常还在技能实现中组合 DEX、LUK、Job Level、技能等级、材料和声望。

## 20.2 商人系统

经典商人系包含：

- Discount / Overcharge；
- Pushcart 与负重；
- Vending；
- Mammonite 的 Zeny 消耗；
- 铁匠锻造与名声；
- 炼金制药与排名。

NPC 商店价格、玩家商店价格和道具脚本价格修正是不同层次。

## 20.3 重量

职业基础最大负重来自 `job_stats.yml`，STR、技能、手推车和装备进一步修改。物品重量在 DB 中通常以 0.1 为显示单位保存。

负重同时影响：

- 自然恢复；
- 拾取；
- 开箱；
- 90% major overweight 的攻击/技能限制；
- 手推车容量。

## 20.4 Zeny 与掉落

怪物 Zeny、MVP 奖励、任务脚本和技能消耗并非统一表。要做经济模拟，应从“来源/消耗事件”建账，而不是只汇总物品价格。
