# 01. 角色成长：Base、Job、属性点与转生

## 1.1 两条等级轴

- `Base Level`：提供属性点，并参与 HP/SP 表、HIT、FLEE 等计算；
- `Job Level`：提供技能点和职业属性奖励（Job Bonus）。

经验需求不是统一函数，而是 `job_exp.yml` 的职业组查表数据。HP/SP 基础值同样由 `job_basepoints.yml` 按职业与 Base Level 查表。

## 1.2 属性点总量

Lv1 初始累计属性点为 48。角色升到新等级 `L` 时，获得：

```text
新增属性点(L) = 3 + floor((L - 1) / 5),  L >= 2
```

因此：

```text
Lv99 累计属性点 = 1273
转生职业额外属性点 = 52
```

完整逐级累计表以 `db/pre-re/statpoint.yml` 为准。

## 1.3 单次加点成本

把某项“基础属性”从当前值 `S` 提高 1 点，消耗：

```text
Cost(S -> S+1) = 1 + floor((S + 9) / 10)
```

典型断点：

| 当前值 | 提升后的值 | 消耗 |
|---:|---:|---:|
| 1 | 2 | 2 |
| 9 | 10 | 2 |
| 10 | 11 | 2 |
| 11 | 12 | 3 |
| 20 | 21 | 3 |
| 21 | 22 | 4 |
| 91 | 92 | 11 |

这解释了为什么经典 RO 配点既要考虑“攻击断点”，也要考虑“属性点成本断点”。

## 1.4 Job Bonus

职业在指定 Job Level 获得固定 STR/AGI/VIT/INT/DEX/LUK 奖励。它不是玩家手动加点，也不增加下一点属性的成本。

权威数据：

```text
db/pre-re/job_stats.yml -> BonusStats
```

## 1.5 转生

经典转生主线：

```text
普通二转 Base 99 / Job 50
  -> Novice High
  -> High 一转
  -> 转生二转
```

转生职业的典型量化差异：

- 额外 52 属性点；
- HP/SP 基础值在最终计算中获得 1.25 倍转生倍率；
- 获得转生职业技能树；
- Job Bonus 和 Job EXP 使用对应转生职业表。

## 1.6 上限

本规则集中普通和转生职业的六维基础属性默认上限为 99。Baby 变体有独立上限，应从职业表读取，不要把普通上限直接套用。
