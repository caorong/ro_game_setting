# 18. 队伍、公会、PvP 与 GvG

## 18.1 队伍经验与掉落

队伍系统会在怪物基础 EXP/掉落之后介入，涉及：

- 贡献者和击杀者；
- 队伍共享开关；
- 成员距离与在线状态；
- 均分与人数奖励；
- 道具拾取规则；
- Autoloot；
- 地图和活动修正。

这些参数由 `party.cpp` 与 battle config 驱动。生成器应导出实际配置，而不是在怪物表里重复写最终收益。

## 18.2 公会

可量化数据包括：

- 公会等级与 EXP；
- 公会技能树；
- 人数上限；
- 城堡、Guardian 与投资；
- WoE 状态和地图标志。

相关表：`exp_guild.yml`、`guild_skill_tree.yml`、`castle_db.yml`。

## 18.3 PvP/GvG 伤害

PvP、GvG、Battleground 会在通用伤害管线后应用地图类型和技能类别修正。某些技能、击退、陷阱、状态和装备破坏在 GvG 中有专门规则。

实现原则：

```text
先复用 PvE 通用伤害上下文
再应用地图模式修正
```

不要为 PvP 单独复制一套容易漂移的基础属性公式。
