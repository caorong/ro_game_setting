# 06. 物理伤害完整管线

## 6.1 为什么不能写成 ATK × 技能倍率

Pre-Renewal 武器伤害由多个独立组件组成，且执行顺序会改变结果。

## 6.2 普通攻击核心管线

```text
1. 建立攻击上下文：距离、手、弹药、技能、目标
2. Lucky Dodge / 多重攻击 / 暴击 / 命中判定
3. 计算 Status ATK
4. 计算主手与副手 Weapon ATK 随机值
5. 计算弹药、锻造星砂、过精炼等组件
6. 应用技能基础伤害和倍率
7. 应用 DEF 前修正
8. Hard DEF 百分比减伤
9. Soft DEF 随机减伤
10. 追加精炼攻击（经典路径在 DEF 后）
11. 最低伤害处理
12. 追加武器熟练度等 Mastery
13. 攻击属性 × 防御属性等级
14. 武器体型修正
15. 种族、阶级、Boss、远近距离、卡片和装备脚本
16. 双持左右手惩罚
17. PvP / GvG / Battleground 和最终修正
18. 多段显示与实际伤害分配
```

不同技能会跳过、替换或重复某些步骤。

## 6.3 武器攻击随机区间

对玩家非暴击主路径：

```text
WeaponATK_MAX = WeaponATK
WeaponATK_MIN = min(
    WeaponATK_MAX,
    floor(DEX * (80 + 20 * WeaponLevel) / 100)
)
```

弓等远程武器还会把最小攻击按武器攻击再次缩放；精确行为以 `battle_calc_base_damage` 为准。

一般非暴击会在最小值和最大值间随机，暴击取最大武器攻击。源码部分随机函数使用不含上界区间，复刻时要保留这一细节。

## 6.4 弹药

远程武器的弹药攻击是独立组件：

- 普通攻击通常随机取得弹药攻击的一部分；
- 暴击使用完整弹药攻击；
- 弹药自身可携带属性与脚本修正；
- 默认 `arrow_decrement=1`，攻击会消耗弹药。

## 6.5 双持

双持需要分别计算：

```text
right-hand damage
left-hand damage
```

左右手武器攻击、属性、体型、卡片继承和最终惩罚并不完全相同。默认 `left_cardfix_to_right=yes` 会影响部分卡片/属性共享行为。

## 6.6 多段攻击

`HitCount` 可能表示：

1. 真正多次独立命中；
2. 一次总伤害拆成多个显示数字；
3. 每段独立触发附加效果；
4. 只影响客户端表现或受击延迟。

必须结合技能 DB 标志和技能实现判断，不能只用 `total_damage / hit_count`。

## 6.7 最低伤害

普通路径通常在防御后保证至少 1 点伤害，但植物、特殊目标、无效属性、被格挡技能和“拆分多段显示”会产生例外。
